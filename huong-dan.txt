 
                  Hướng dẫn FE — Upload ảnh xe (trước/sau khi rửa) lên Firebase Storage              Tóm tắt:         FE upload file             thẳng         lên Firebase Storage, lấy về URL, rồi gọi API backend để lưu URL đó vào booking. File             không         đi qua backend.          Stack FE: React + Vite + TS. Firebase             đã được khởi tạo sẵn         (dùng cho Auth trong               firebase-config.ts    ) → chỉ cần thêm             module Storage         vào đúng app đó, không tạo app mới.                        Luồng tổng quan (3 bước)                         1. FE → Firebase     Staff chọn file → uploadBytes() đẩy thẳng lên Storage                 2. Firebase → FE     getDownloadURL() trả về URL https của ảnh                 3. FE → Backend      POST URL + type + note → BE lưu vào bảng BookingImages                         Ràng buộc phải nhớ (BE trả 400/403 nếu sai)                   Chỉ tài khoản Staff         mới được thêm/xoá ảnh. Request phải kèm               Authorization: Bearer &lt;JWT của app&gt;         — token đăng nhập backend,             không         phải token Firebase. Role ≠ Staff →               403    .                   Type         chỉ nhận đúng chuỗi               "BeforeWash"         hoặc               "AfterWash"         (phân biệt hoa/thường).                   Đúng giai đoạn:         ảnh               BeforeWash         chỉ gắn khi booking đang               CheckedIn    /          InProgress    ; ảnh               AfterWash         khi đã               Completed    /          CheckedOut    . Sai lúc →               400    .                   URL         phải là               https    , ≤ 1000 ký tự.               note         tùy chọn, ≤ 500 ký tự.
